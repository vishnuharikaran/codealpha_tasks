# Stock Portfolio Tracker

A simple text-based console application to track stock investments, portfolio value, and performance, built with Python 3.

## 📝 Project Description

The Stock Portfolio Tracker is a command-line tool developed as part of the **CodeAlpha** Python Programming Internship. It enables users to manage their stock portfolio by tracking stock holdings, shares, buy prices, and calculated portfolio performance.

---

## ✨ Features

*(Phase 1: Project structure initialized. Features will be implemented in upcoming phases)*

- Add and remove stock holdings
- View current portfolio summary
- Calculate total portfolio value and profit/loss

---

## 🛠️ Technologies Used

- **Language**: Python 3.x (Standard Library only)
- **User Interface**: Console / Command Line Interface (CLI)

---

## ⚙️ Installation

No third-party packages or external dependencies required. Ensure Python 3.x is installed on your computer.

1. Navigate to the project directory:

   ```bash
   cd Stock_Portfolio_Tracker
   ```

---

## 🚀 Usage

Run the Python script directly from your command prompt or terminal:

```bash
python stock_tracker.py
```
