# Basic Chatbot

A simple text-based console chatbot built using Python 3.

## 📝 Project Description

The Basic Chatbot is a rule-based terminal application developed as part of the **CodeAlpha** Python Programming Internship. It responds to user inputs using predefined rules, keyword matching, and standard conditional logic without relying on external AI APIs, machine learning models, or external services.

---

## ✨ Features

*(Phase 1: Project structure initialized. Features will be implemented in upcoming phases)*

- Interactive text-based terminal conversation loop
- Rule-based keyword response matching
- Predefined greeting, inquiry, and farewell responses
- Fallback handling for unrecognized user queries
- Conversation exit capability

---

## 🛠️ Technologies Used

- **Language**: Python 3.x (Standard Library only)
- **User Interface**: Command Line Interface (CLI) / Console

---

## ⚙️ Installation

No external libraries, AI frameworks, or API keys required. Ensure Python 3.x is installed on your computer.

1. Navigate to the project directory:

   ```bash

   ```
